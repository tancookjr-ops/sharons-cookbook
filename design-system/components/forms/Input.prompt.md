# Input

A single-line text field — cream-white surface, hairline border, and a soft sage focus ring (`0 0 0 3px --primary-soft`). Hover warms the border to driftwood. Accepts all native `<input>` props.

```jsx
<Input placeholder="Search recipes, ingredients, tags…" type="search" />
<Input size="sm" type="number" min="0" placeholder="Amt" />
```

Pair with `Field` for a label. Use `type="search"` for the recipe search bar.
