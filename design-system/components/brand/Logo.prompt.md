# Logo

The Sharon's Cookbook brand lock-up — the app's own herb-leaf mark (a sage leaf with a cream midrib and veins) with or without the wordmark set in the display serif. Colours are token-driven, so it adapts to light/dark.

```jsx
<Logo />                    {/* mark + "Sharon's Cookbook" */}
<Logo variant="mark" size={40} />   {/* leaf only */}
```

The same mark ships as raster app icons in `assets/brand/` (`app-icon-512.png`, `apple-touch-icon.png`, …) for favicons and PWA install. Never substitute another mark — this leaf is the brand.
